Панель загрузки изображений с iPhone. Обновляет файлы прямо в твоём GitHub-репозитории.

1. Доступ к GitHub

🔐 Используй fine-grained personal access token, ограниченный только репозиторием CarsChibi.site с разрешением Contents: Read and write. Никому не отправляй ключ. Он хранится только в памяти этой вкладки и исчезнет при её закрытии.

Создать ключ: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.

2. Выбери изображение

Изображение будет сохранено как PNG. Рекомендуется квадратное изображение с прозрачным фоном, до 5 МБ.

После успешной загрузки GitHub Pages обычно обновляет картинку за несколько минут. Если видишь старую — обнови страницу или открой её в приватной вкладке.
